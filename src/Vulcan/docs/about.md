# About Vulcan

Version: 0.2.0

Vulcan combines an Intel 8080 emulator and assembler with a Java Swing development workspace.
Its Editor, Debugger, Display, consoles, and Terminal provide a place to write assembly,
inspect instructions and memory, and experiment with text programs and games.

The project uses Java 21. Launch `Vulcan.Vulcan` from the existing IDE project.

File icons come from installed Windows associations. Control glyphs come from installed
Segoe Fluent Icons. The red ASM icon is VS Code's Seti glyph; its attribution is in
`res/Seti-ThirdPartyNotices.txt`. `Icons.java` lists the packaged icon names.

This is a developing emulator. Hardware devices and a C compiler are outside its current implementation.
